שני מאגרים וקטוריים, embeddings של text-embedding-3-small:

🔒 אבטחה

ה-Personal Access Token של Airtable לא נמצא באפליקציה. כל פנייה עוברת דרך פונקציית שרת אל ה-webhook של WF13, וכתובת ה-webhook שמורה כ-secret בצד השרת בלבד ואינה מגיעה לדפדפן. בדיקת האימות המלאה נמצאת ב-docs/security-check.md.

טיפול בשגיאות — שתי שכבות

ברמת הצומת

בכל אוטומציה, צמתים קריטיים מוגדרים Continue (using error output) עם ניסיון חוזר, ומנותבים לענף Error ייעודי. כשלון נקודתי לא מפיל את הזרימה כולה.

ברמת האוטומציה

WF0 מוגדר כ-Error Workflow בכל אחת מהאוטומציות. כשהרצת production נכשלת, n8n מפעיל אותו אוטומטית והוא שולח לטלגרם את שם האוטומציה, הצומת שנכשל, הודעת השגיאה המקורית וקישור ישיר להרצה.
